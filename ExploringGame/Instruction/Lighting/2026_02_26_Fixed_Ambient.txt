We want some rooms to have their ambient light set to a specific value, despite not having any point lights

# NOTES

- however there's some areas where we just want the room to have a certain base brightness
- we still want to use the existing room-based light calculations

	- and this room can add brightness to surrounding rooms
- the only difference is the room doesn't get any point lights

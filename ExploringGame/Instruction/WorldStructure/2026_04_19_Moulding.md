# GOAL
Add a Shape that will add moulding (trim) around a shape

# CONTEXT
- `Agent Docs\project_map.md`

# INPUTS
- Parent Shape (to apply the moulding to)
- Side (which side of the parent to apply the moulding)
- MouldingSides (which sides get moulding. treated as a flags enum here)
- Color (shade of the moulding)
- Size (how wide or tall a piece of moulding is)
- Thickness (how far out from the parent shape the moulding is

## EXAMPLES 
	- We want to add moulding on the North wall of the house, and the moulding will go on the West and East edge
	- We want to add moulding around the West face of a window, on the North, South, Top, and Bottom edges

# SHAPE DETAIL
- use Box shapes for each trimming side
- create a Trimming Theme, a single-textured theme using TextureSheetKey.Upstairs and TextureKey.Plain
- no collision is needed
- place in `GeometryBuilder\Shapes\Structures\`
- don't apply this new shape anywhere, I will do that myself. I only want you to define the shape class

# RESEARCH

## Rendering Transformation Pipeline

### Overview
The rendering system uses standard 3D graphics pipeline with World-View-Projection matrix transformations.

### Key Components

#### 1. Player/Camera (`Entities/Player.cs`)
- Player implements `ICamera` interface
- `CreateViewMatrix()` method generates the view matrix based on:
  - **Player Position**: Used in `Matrix.CreateLookAt(Position, Position + lookDir, Vector3.Up)`
  - **Player Rotation**: Yaw and Pitch determine look direction via `Matrix.CreateFromYawPitchRoll(Rotation.Yaw, Rotation.Pitch, 0)`

#### 2. Camera Service (`Services/CameraService.cs`)
- Updates the `View` matrix each frame by calling `_current.CreateViewMatrix()`
- `Projection` matrix is static, created with `Matrix.CreatePerspectiveFieldOfView(70° FOV, aspect ratio, near=0.1f, far=100f)`

#### 3. Shape World Matrix (`GeometryBuilder/Shape.cs`)
- Each shape has a `GetWorldMatrix()` method (virtual, can be overridden)
- Default implementation:
  ```csharp
  public virtual Matrix GetWorldMatrix()
  {
	  var scaleMatrix = Matrix.Identity;
	  var rotationMatrix = Rotation?.AsMatrix() ?? Matrix.Identity;
	  return scaleMatrix * rotationMatrix * Matrix.CreateTranslation(Position);
  }
  ```
- This positions the shape in world space based on its `Position` property

#### 4. Render Pipeline (`Rendering/RenderEffect.cs`)
- `BasicRenderEffect.SetParameters()` applies transformations:
  ```csharp
  var world = shapeBuffer.Shape.GetWorldMatrix();
  effect.World = world;
  effect.View = view;
  effect.Projection = projection;
  ```
- The GPU shader performs: `finalPosition = position * World * View * Projection`
- **World matrix**: Transforms from model space to world space (includes shape position)
- **View matrix**: Transforms from world space to camera space (subtracts player position, applies rotation)
- **Projection matrix**: Transforms from camera space to clip space (perspective)

### View Matrix Deep Dive

#### Matrix.CreateLookAt Behavior (XNA/MonoGame)
The `Matrix.CreateLookAt(cameraPosition, cameraTarget, cameraUpVector)` function creates a view matrix that:
1. **Translates** the world so the camera position becomes the origin (subtracts cameraPosition from all vertices)
2. **Rotates** the world so the camera looks down the -Z axis
3. Creates a right-handed coordinate system aligned with the camera

**Mathematical composition**: `View = RotationMatrix * TranslationMatrix(-cameraPosition)`

**Key insight**: The View matrix contains BOTH:
- **Translation component**: Inverse of camera position (-Position.X, -Position.Y, -Position.Z)
- **Rotation component**: Inverse of camera rotation (aligns world to camera orientation)

#### View Matrix Flow Through System

**Step 1**: Game Update Loop (`Game1.cs`, line 173)
```csharp
_cameraService.Update();
```

**Step 2**: CameraService.Update() (`Services/CameraService.cs`, line 24-26)
```csharp
public void Update()
{
	View = _current.CreateViewMatrix();  // Calls Player.CreateViewMatrix()
}
```
- Refreshes View matrix every frame
- Captures current player Position and Rotation
- Stores in `CameraService.View` property

**Step 3**: Rendering (`Game1.cs`, line 184)
```csharp
_renderEffect.Draw(graphicsDevice, levelData.ShapeBuffers, _cameraService.View, _cameraService.Projection);
```
- Passes View matrix from CameraService to rendering system

**Step 4**: Per-Shape Rendering (`Rendering/RenderEffect.cs`, line 99-104)
```csharp
public override void SetParameters(BasicEffect effect, ShapeBuffer shapeBuffer, Matrix view, Matrix projection)
{
	var world = shapeBuffer.Shape.GetWorldMatrix();
	effect.World = world;
	effect.View = view;
	effect.Projection = projection;
}
```
- Gets shape's World matrix (contains shape's position/rotation)
- Assigns World, View, Projection to shader effect parameters

**Step 5**: GPU Shader Transform (`Content/PointLightEffect.fx`, lines 34-37)
```hlsl
output.Position = mul(input.Position, World);      // Model → World (adds shape position)
output.Position = mul(output.Position, View);      // World → Camera (subtracts player position)
output.Position = mul(output.Position, Projection); // Camera → Clip (perspective)
```

### Complete Transformation Breakdown

For a normal shape at world position (10, 5, 20) when player is at (8, 2, 15):

1. **World Matrix**: Translates vertex from model origin to (10, 5, 20) in world space
2. **View Matrix**: 
   - Translation: Moves vertex by (-8, -2, -15) → vertex now at (2, 3, 5) relative to player
   - Rotation: Rotates based on player's look direction
3. **Projection Matrix**: Applies perspective to create depth

**Result**: Shape appears at correct position relative to player.

### Skybox Problem

For a skybox, we want it to appear infinitely far away and always centered on the player:
- **Current behavior**: World matrix positions skybox at fixed world coordinates, View matrix translates it relative to player → skybox moves as player moves ❌
- **Desired behavior**: Skybox should only rotate with player, not translate ✓

**The Challenge**: The View matrix's translation component must not affect the skybox, but its rotation component should.

2. **Singleton Pattern**: Use static Instance properties to share skybox geometry
3. **Depth Strategy**: Read depth buffer, don't write (DepthBufferWriteEnable = false)

5. **Build Quality**: Skybox always builds at full quality (QualityLevel.Full)

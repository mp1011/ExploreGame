# GOAL
Update our "proof of concept" for grass rendering to me more reusable and to better integrate with existing coding patterns.

# FILES
- Rendering\GrassRenderer.cs
- Content\GrassEffect.fx

# DESIRED CHANGES
- Old: GrassRenderer tightly coupled to FrontYard shape type
- New:
    - create a new shape, GrassSurface, which can be given as a child of FrontYard (or any other shape that needs grass)
- Old: GrassRenderer created triangle geometry for grass
- New:
    - triangles created in GrassSurface's BuildInternal method, like any other shape
- Old: GrassRenderer creates Vertex Buffers
- New:
    - create buffers through ShapeBufferCreator, giving it knowledge to use special code for the GrassSurface type
    - create a GrassVertexBufferBuilder service class to do the actual work

Render Flow:
1. GrassSurface creates a ShapeBuffer like any other shape
2. LevelData class gets a new GrassShapeBuffers, which holds the buffers for GrassSurface shapes (removing them from the normal shape buffer collection)
3. In DrawWorld, add an extra pass to draw shapes from GrassShapeBuffers
    - create an instance of IRenderEffect to draw using the new shader

# Glass Windows Implementation Plan

## Overview

Create a "GlassPane" shape to simulate windows. This will slightly blur the view behind the window.

## Context
- Instruction\Rendering\2026_04_15_Render_cleanup.md

## GlassPane Shape
- a box shape, intended to be see through
- insert one in the "Window" shape

## Rendering
- create a new IRenderPass for rendering windows
- this pass comes after drawing regular geometry
- this pass uses a custom shader that applies a slight blur, simulating looking through a window

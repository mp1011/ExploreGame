# GOAL
To make our existing pathfinding code more generally usable, specifically for tracing the "path" of light through rooms.

# CONTEXT
- copilot, please give a quick summary of each of these files and add it to this document
- Logics\Pathfinding\PathFinder.cs
	- A service used by entities to navigate through the world. 
	- It takes a physics service, waypoint graph, and a collidable entity. 
	- It maintains a primary target and current target, and uses A* pathfinding through waypoints to navigate around obstacles when direct line-of-sight isn't available. 
	- Includes stuck detection and random walk behavior when the entity gets stuck.
- Logics\Pathfinding\Waypoint.cs
	- Represents a single node in the pathfinding graph. 
	- Each waypoint is associated with a Room and stores its own list of neighbor waypoints. 
	- Contains an IsTargeted boolean for visualization/debugging. 
	- Inherits from PlaceableShape but renders nothing (empty triangle array). 
	- Waypoints form the graph structure by each maintaining their own neighbor list.
- Logics\Pathfinding\WaypointGraph.cs
	- Builds and manages the waypoint graph for a WorldSegment. 
	- Creates one waypoint per room and connects them based on room connections. 
	- Provides pathfinding via A* algorithm and helper methods to find waypoints by position. 
	- Currently owns the graph structure through a dictionary of rooms to waypoints.

# ACCEPTANCE CRITERIA
1. The concept of a "Room Graph", independent of waypoints or physics entities, is available from LoadedLevelData
2. The existing "Waypoint" and "WaypointGraph" classes are refactored to make use of this graph
3. All existing unit tests pass
4. Placeholder classes are put in place for future lighting work (details of the classes to be determined)

# TECHNICAL DETAILS
1. room graph knows which Rooms are connected to which other Room
2. the class can also have methods for finding a path between two rooms
3. RoomGraph should be initialized in the LoadSegment method of LoadedLevelData
4. The resulting RoomGraph should be exposed as a property of LoadedLevelData
4. RoomGraph will encompass ALL loaded WorldSegments, so there will only be a single instance available at a time
